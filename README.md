Общая структура проекта состоит в следующем:
app - Главная папка проекта в котором находится приложение.
#### Папка -  `app`
- `api` – Интерфейс для внешних запросов к боту, по связанной теме, например если сайт запрашивает у неё статистику.
- `cogs` – Основные модули бота, в которых находятся команды.
> - admin – Команды администраторов.
> - diamos – Младшая версия AMOS.
> - event – Любые виды циклических событий, события дискорда или события disnake.
> - fun – Команды для развлечения пользователей
> - message – Файл чисто для обработки текстового потока, реакции, настроение и другой стаф.
> - system – Различные команды для автоматизации или разработки.
> - utils – Различные команды не относящиеся к другим категориям
- `media` – Папка с временными файлами, которые требуются дольше действия одной команды.
- `static` – Материалы требуемые для команд на постоянной основе, картинки, стили и другие вещи которые дорого грузить в базу данных.
- `system` – Различные подсистемы, для чистки, обновления бд в CD или других вещей относящиеся к самому боту системно, без участия пользователя.
> -  db_interface – Обновление, очистка и починка бд.
> - logger – Логгирование системных событий (NON-USER).
> - struct_cleaner – Создание структуры папок, очистки старых файлов и структурирование логов (Аривирование).

#### Папка - `logs`
Фактически просло место логирования бота. Разбивается по месяцам с ежедневным логированием событий которые переписываются из базы данных. Организация по принципу в месяце есть логи каждый день. Месяц закончился папка месяца архивируется и оставляется. Если закончился год, то все месяцы данного года собираются и архивируются в год.
Год > Месяц > День.
Логирование состоит из множества параметров для статистического анализа сервера на основе чисел. Далее будут перечислены параметры по ежедневным логам, так как месячные и годовые просто архивированные ежедневные.
1. Дата и время лога
2. Число сообщений в текущий день
3. Число пользователей онлайн (по часам)
4. Общее время прошедшее с последнего перезапуска

Остальные данные будут добавляться по мере надобности в них.

#### Папка – `tests`
Просто место для автоматического тестирования модулей на корректность работы. Например API.
